# Домашний SOC стенд (Портфолио)

Репозиторий с материалами по развертыванию и настройке домашней лаборатории для практики в Blue Team / SOC. Включает этапы развертывания инфраструктуры, настройки сбора телеметрии, эмуляция атак по MITRE ATT&CK, создания правил детектирования и отчетов.

## Архитектура
Стенд развернут на базе VirtualBox в изолированной сети 10.10.10.0/24 (Host-Only).

- SIEM (Ubuntu 24.04): 10.10.10.10 (Wazuh 4.14.9 all-in-one)
- Жертва (Windows 11): 10.10.10.20 (Sysmon, Wazuh Agent, включенный аудит)
- Атакующий (Kali Linux): 10.10.10.30 (nxc, nmap, сетевое окружение изолировано от домашней сети)

## Эмуляция атак и детектирование
В рамках проекта проведены атаки, собран телеметрия и написаны правила детектирования.

| Техника | Описание | Отчет | Правило |
| :--- | :--- | :--- | :--- |
| **T1059.001** | Encoded PowerShell Execution | [INC-001](reports/2026-10-28-t1059-powershell.md) | [DET-001](detections/cards/det-001.md) |
| **T1053.005** | Scheduled Task (Persistence) | [INC-002](reports/2026-10-28-t1053-scheduled-task.md) | [DET-002](detections/cards/det-002.md) |
| **T1110.003** | SMB Password Spray | [INC-003](reports/2026-10-28-t1110-password-spray.md) | [DET-003](detections/cards/det-003.md) |

## Телеметрия
Детекты построены на базе событий Windows Security (Event ID 4688, 4698, 4625) и Sysmon (Event ID 1). Для каждого детекта написана карточка (гипотеза, логика, FP-анализ) и приложено Sigma-правило.

- Матрица телеметрии: [docs/telemetry-matrix.md](docs/telemetry-matrix.md)
- Sigma-правила: [detections/sigma/](detections/sigma/)

## Навыки
- Развертывание и настройка Wazuh (SIEM) и агентов.
- Настройка Windows Audit Policy и установка Sysmon.
- Написание поисковых запросов в Wazuh Dashboard.
- Анализ логов Windows и понимание Event ID.
- Создание правил детектирования (Sigma).
- Работа с фреймворком MITRE ATT&CK.
- Документирование инцидентов.

## Структура репозитория
- detections/ — карточки детектов и Sigma-правила.
- docs/ — архитектура, журнал работ, матрица телеметрии, roadmap.
- evidence/ — скриншоты и JSON-логи, подтверждающие срабатывание алертов.
- eports/ — отчеты об инцидентах (INC).
