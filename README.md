# soc-lab-junior

Домашний SOC-стенд: Wazuh + Windows-жертва с Sysmon + Kali.
Цель — пройти путь от эмуляции атаки до письменного разбора и рабочего детекта.

## Стенд

| Компонент | Роль | vCPU / RAM / Диск |
|---|---|---|
| Wazuh (Ubuntu) | SIEM | 4 / 8 ГБ / 100 ГБ |
| Windows 10 22H2 | жертва | 2 / 4 ГБ / 60 ГБ |
| Kali Linux | атакующий | 2 / 4 ГБ / 40 ГБ |

Схема сетей и ресурсы: [docs/architecture.md](docs/architecture.md)

## Структура

```
docs/        архитектура, телеметрия, журнал
reports/     разборы инцидентов
detections/  Sigma-правила и карточки детектов
evidence/    скриншоты и выгрузки алертов
```

## Прогресс

- [ ] Фаза 1 — стенд поднят, изоляция проверена
- [ ] Фаза 2 — телеметрия проверена ([docs/telemetry-matrix.md](docs/telemetry-matrix.md))
- [ ] Фаза 3 — 3 атаки проведены
- [ ] Фаза 4 — 3 отчёта в `reports/`
- [ ] Фаза 5 — 5 детектов в `detections/`
- [ ] Фаза 6 — видео 5 мин + one-pager
- [ ] Фаза 7 — репетиция демо

## Ограничения

Честно и конкретно: чего стенд не умеет, какие логи не собираются, почему.
