# Архитектура стенда

## Гипервизор
- **Хост:** Windows 10 Home 22H2 (i3-12100F, 4 ядра / 8 потоков, 16 ГБ RAM)
- **Гипервизор:** VirtualBox 7.2.6
- **Сеть:** Host-Only Ethernet Adapter (10.10.10.1/24) + NAT (для обновлений)

## Виртуальные машины

| VM | ОС | vCPU | RAM | Диск | IP | Роль |
|---|---|---|---|---|---|---|
| siem | Ubuntu Server 24.04.5 | 3 | 6144 МБ | 51 ГБ | 10.10.10.10 | Wazuh all-in-one |
| win11 | Windows 11 Pro | 2 | 4096 МБ | 40 ГБ | 10.10.10.20 | Жертва (Sysmon, агент Wazuh) |
| kali | Kali Linux | 2 | 2048 МБ | 25 ГБ | 10.10.10.30 | Атакующий |

## Сеть
- **NAT (10.0.2.0/24):** выход в интернет для обновлений.
- **Host-Only (10.10.10.0/24):** изолированная лабораторная сеть. Трафик в домашнюю сеть (192.168.3.0/24) и Radmin VPN (26.0.0.0/8) заблокирован на уровне маршрутов внутри Kali.

## Изоляция
- Kali не видит домашнюю сеть (`ping 192.168.3.1` → `Invalid argument`).
- Kali не видит Radmin VPN (`ping 26.182.187.193` → `Invalid argument`).
- Kali видит SIEM (`ping 10.10.10.10`) и Windows (`ping 10.10.10.20`).
