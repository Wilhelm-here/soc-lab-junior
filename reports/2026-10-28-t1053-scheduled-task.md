# INC-002 — Scheduled Task Creation (T1053.005)

**Дата:** 2026-10-28 | **Автор:** SOC Analyst | **Severity:** High | **Статус:** Closed

## Summary
На хосте ictim (10.10.10.20) зафиксировано создание задачи в Планировщике Windows (WindowsUpdateCheck). Техника используется злоумышленниками для закрепления в системе (Persistence) и запуска вредоносного кода при входе пользователя.

## Environment
- **Хост:** victim (Windows 11, IP 10.10.10.20)
- **SIEM:** Wazuh 4.14.9 (10.10.10.10)
- **Источники логов:** Windows Security (4698, 4688), Sysmon (EventID 1)

## Detection
- **Security 4698:** Сработало правило 60228 (A scheduled task was created). Видно имя задачи и автора.
- **Sysmon 1:** Сработало правило 67027. Видна командная строка schtasks.exe /create /tn "WindowsUpdateCheck" /tr "calc.exe" /sc onlogon /f.

## IOCs
- Имя задачи: WindowsUpdateCheck (имитация легитимного имени)
- Командная строка: schtasks.exe /create /tn "WindowsUpdateCheck" /tr "calc.exe" /sc onlogon /f

## MITRE ATT&CK
- **T1053.005**: Scheduled Task/Job: Scheduled Task

## False positives
Легитимные администраторы и установщики ПО часто создают задачи. Ложные срабатывания можно отфильтровать по:
- Имени задачи (если оно странное или имитирует системное);
- Пути к исполняемому файлу (calc.exe в системной папке — подозрительно для обновления);
- Пользователю, создавшему задачу.

## Gaps
- Нет проверки цифровой подписи исполняемого файла, который запускает задача (в данном случае calc.exe).
- Отсутствует мониторинг сетевых соединений от процесса, запущенного задачей.

## Recommendation
1. Настроить алертинг на создание задач с нетипичными именами или запускающими подозрительные бинарники.
2. Ограничить права на создание задач для обычных пользователей через GPO.

## Lessons learned
Sysmon дал полную командную строку, а Security 4698 подтвердил факт создания объекта. Вместе они дают полную картину без необходимости смотреть в сам Планировщик.
